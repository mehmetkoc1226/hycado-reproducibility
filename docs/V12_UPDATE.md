# Manuscript v12 update

## Completed comparisons included

The original 548-image VAL controls are retained alongside YOLO-1280/1536 and genuine SAHI-640/800. The current table set includes paired global-fusion and stronger-baseline intervals, matched false-positive-budget recall, and size/object-count diagnostics. Size-stratified recall is not AP-small.

Stage 18 evaluates the original 800-input cascade, YOLO-800/1280 and three matched relocations on 1610 test-dev images. Stage 19 evaluates the full 1280 variant on the 647-image internal-development subset of official TRAIN. Stage 20 evaluates both fixed 1280 variants on test-dev with source-bound reports and paired 1000-draw intervals.

HyCADO-1280 uses YOLO-1280 for both region selection and final global detections. The other variant retains regions selected at 800 and fuses their crop predictions with global YOLO-1280 detections. Both retain the crop-trained RT-DETR-L weights, crop input 960 and score multiplier 0.25.

## Interpretation

- Training seed 42 identifies one trained model set, not multiple independent replications.
- The internal-development subset is part of official TRAIN, not an external dataset.
- Original test-dev evaluation preceded the 1280 extension. The extension is exploratory and cannot be described as an untouched confirmatory test.
- AP is the pinned toolkit aggregation. Published COCO/leaderboard numbers using other protocols are not interchangeable.
- Proxy-cluster bootstrap intervals condition on fixed models. Filename/hash groups are not verified independent scenes.
- The tested 1280 variants improve on YOLO-1280 under this protocol; superiority to every high-resolution/sliced detector is not established.
- No new training, GPU inference, threshold search or timing benchmark was performed for this repository update.
